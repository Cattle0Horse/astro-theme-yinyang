## 正文与旁注

<!-- sidenote:1 -->**阅读**与<!-- sidenote:2 -->记录<!-- /sidenote:1 -->各有节奏<!-- /sidenote:2 -->。读过之后留下问题，再带着问题回到文本。

普通脚注可以放在这里。[^reading]

<!-- sidenote:1
有些线索值得在阅读时保留在正文旁边。
-->

## 表达与结构

下面的图片来自 YinYang 示例站。

![YinYang 示例站的页面背景](./附件/阅读背景.png)

| 形式 | 用途 |
| :--- | :--- |
| 长文 | 展开一个问题 |
| 短记 | 保留一次观察 |

```ts
const observation = { read: true, reflect: true }
const record = { ...observation, share: true }
const notes = [
  '先把读到的观点写下来',
  '记录当时的问题',
  '留一个能回到原文的链接',
  '区分作者的话与自己的判断',
  '写下暂时无法解释的细节',
  '给后续验证保留线索',
  '在有新证据以后更新记录',
  '保留前后变化的理由',
  '定期回到最初的问题',
  '整理出可以分享的版本',
  '补充来源与上下文',
  '把写作当成下一次阅读的起点'
]
const next = { ...record, notes }
```

行内公式 $x^2 + y^2 = r^2$ 可以穿插在正文里。块公式也有独立的排版。

$$
\sum_{k=1}^{n} k = \frac{n(n+1)}{2}
$$
